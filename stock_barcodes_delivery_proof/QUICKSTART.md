# Quick Start Guide - Stock Barcodes Delivery Proof

## Instalación Rápida (5 minutos)

### 1. Instalar el módulo

```bash
# En Odoo UI:
Apps > Update Apps List > Search "Stock Barcodes Delivery Proof" > Install
```

### 2. Configurar (1 minuto)

```
Inventory > Configuration > Settings
  └─ Scroll to "Delivery Proof of Delivery"
  └─ Check "Enable Delivery Proof Capture"
  └─ Select "Per Picking"
  └─ Save
```

### 3. Probar (2 minutos)

```
1. Create a delivery order (outgoing picking)
2. Click "Barcode Scanner" button
3. Click "Photo (0)" button (bottom bar)
4. Allow camera access
5. Click camera button to capture
6. Click "Use Photo"
7. Photo appears in gallery
8. Click "Validate" to complete delivery
```

## Uso Diario

### Desde Scanner de Barcode:

1. Procesar entrega normalmente (escanear productos)
2. Click botón **"Photo"** (tecla rápida: 9)
3. Capturar 1-2 fotos del paquete/productos
4. Validar entrega

### Ver Fotos Después:

- Abrir entrega > Click smart button **"X Photos"**
- O ir a pestaña **"Delivery Proof"**

## Troubleshooting Rápido

**Cámara no funciona:**

- Permitir acceso en navegador
- Usar HTTPS en producción
- Probar otro navegador

**Botón Photo no aparece:**

- Verificar que es una entrega (outgoing)
- Verificar configuración habilitada
- Refrescar página
